# UX 设计总结 — Core Accounting v1

## 信息架构
9 大模块 53+ 页面：Dashboard / 凭证 / 账表 / 辅助核算 / 财务报表 / 期末 / 出纳 / 固定资产 / 系统管理 / AI 工作台

## 全局布局
Header（Logo+期间+用户头像） | 侧边栏(240/64px 可折叠+搜索+菜单树) | Content | StatusBar
响应式：≥1024 完整布局，<1024 汉堡抽屉

## 核心页面交互
- **凭证列表**：筛选栏→状态标签(草稿/已审/已记账/冲销)→行hover操作→checkbox批量→合计行+分页
- **凭证录入**：科目树搜索选择器→辅助核算弹出→实时借贷平衡指示器→快捷键(Ctrl+S/N/Enter)
- **科目余额表**：树形展开→多期对比列→行点击联查明细账
- **资产负债表**：模板渲染→分级展开→AI 附注区→导出 Excel/PDF
- **期末结转**：模板勾选→试算平衡→AI 10 项检查→一键执行+进度条
- **AI 工作台**：卡片式入口(4 功能) + 嵌入式对话面板 + 全局浮动入口

## 交互规范
- **表格**：排序/筛选/分页/hover行操作/checkbox批量/列显隐/列宽拖拽/合计行
- **表单**：顶标签/红色星号/失焦校验/金额右对齐千分位
- **反馈**：Toast 3s / Modal确认删除 / 进度条长任务 / AI 打字机效果
- **快捷键**：Ctrl+N/S/Enter/F/P, Tab分录跳转, ↑↓行切换

## 角色差异化
| 角色 | 首页 | 菜单差异 |
|------|------|---------|
| 财务人员 | 仪表盘（待办+今日统计） | 无系统管理 |
| 财务经理 | 审核待办+期末状态 | 审核徽章+AI解读突出 |
| 管理员 | 系统管理首页 | 系统管理置顶 |

## 边界处理
空状态→引导文案+操作按钮 | 加载→Skeleton骨架屏/打字机/AI脉动 | 错误→内嵌重试/403权限提示/友好404/断网Banner
