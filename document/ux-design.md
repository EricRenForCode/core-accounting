**侧边栏规格**：
- 宽度：展开 240px / 折叠 64px

- ≥1024px：完整侧边栏

## 4. 交互规范

### 4.1 数据表格通用模式

所有列表页遵循统一交互：

| 行为 | 实现 |
|------|------|
| 排序 | 点击列头排序（升/降/无），科目编码按层级排序 |
| 筛选 | 顶部筛选栏，支持日期范围、下拉选择、模糊搜索 |
| 分页 | 底部分页器：页码 + 每页条数(20/50/100) + 总条数 |
| 行操作 | hover 显示操作按钮组，或行末三点菜单（⋮） |
| 批量操作 | 左侧 checkbox + 顶部批量操作栏 |
| 导出 | 按钮导出当前筛选结果（Excel/PDF） |
| 列显隐 | 齿轮图标选择显示列 |
| 列宽调整 | 拖拽列边界 |
| 合计行 | 固定底部，金额列自动求和 |

### 4.2 表单规范

- **标签位置**：顶部对齐（标签在输入框上方），财务场景字段较多
- **必填标识**：红色星号 *
- **校验时机**：失焦校验 + 提交校验
- **错误展示**：输入框下方红色文字 + 红色边框
- **金额输入**：右对齐，千分位格式化，汇总数字加粗
- **下拉选择**：支持搜索过滤，超过 20 项的下拉必须支持搜索
- **日期选择**：中文日期选择器，支持快捷选择（今天/本月/本年）

### 4.3 反馈机制

| 场景 | 反馈方式 |
|------|---------|
| 保存成功 | 右上角 Toast 绿色 3s 消失 |
| 保存失败 | Toast 红色 + 错误信息 |
| 删除确认 | Modal 对话框：「确定删除凭证 JZ-001？此操作不可撤销。」 |
| 批量操作 | 进度条 + 结果统计（成功 X 条，失败 Y 条） |
| 长时间操作 | 全屏 Loading + 取消按钮（结账、导出、AI 生成） |
| AI 思考中 | 脉动动画 / 打字机效果 |
| 网络异常 | 顶部 Banner 红色提示 + 重试按钮 |

### 4.4 快捷键（财务人员高频）

| 快捷键 | 功能 |
|--------|------|
| Ctrl + N | 新建凭证 |
| Ctrl + S | 保存当前 |
| Ctrl + Enter | 保存并新建 |
| Ctrl + F | 聚焦搜索框 |
| Ctrl + P | 打印当前 |
| Esc | 关闭弹窗/面板 |
| Tab / Shift+Tab | 分录行内跳转 |
| ↑ ↓ | 分录行间切换 |

## 5. 角色差异化体验

### 财务人员（默认角色）

- 进入系统 → 仪表盘（待办：草稿凭证数 / 待审核数 / 今日录入数）
- 侧边栏完整菜单（无权系统管理）
- 凭证录入页为高频页面，可设为首页
- AI 功能可用（生成凭证、查询）

### 财务经理

- 进入系统 → 仪表盘（审核待办 + 期末状态 + 报表概览）
- 菜单额外显示「审核待办」徽章数字
- 凭证列表页默认筛选「待审核」
- 报表页上方 AI 解读入口突出
- 期末处理页为月度必经页面

### 管理员

- 进入系统 → 系统管理首页
- 菜单架构重排：系统管理模块置顶
- 其余模块可访问但非主要操作对象

## 6. 状态与边界处理

### 6.1 空状态

```
┌──────────────────────────────────┐
│                                  │
│          📋                      │
│    还没有凭证记录                 │
│    点击「录入凭证」开始第一笔     │
│                                  │
│       [ 录入凭证 ]               │
│                                  │
└──────────────────────────────────┘
```

各模块空状态均有引导性文案 + 快捷操作按钮。

### 6.2 加载状态

- 列表：Skeleton 骨架屏（灰色占位条动画）
- 详情：居中 Spin
- AI：打字机效果逐字显示
- 导出/结账等长任务：进度条 + 步骤描述

### 6.3 错误状态

- 接口 500：页面内嵌错误卡片 + 重试按钮
- 权限不足：403 页面明确提示所需权限
- 404：友好 404 页 + 返回首页链接
- 网络断开：顶部持续 Banner

## 7. 移动端适配（可选）

内账系统以桌面端为主。如需移动端：

- **PWA**：支持离线查看凭证列表和余额表
- **审批**：财务经理在手机上审核凭证（简化版凭证详情 + 通过/驳回按钮）
- **查询**：手机端只读查询（余额表、明细账），不做录入

### 字体

- 系统默认中文字体栈：`"PingFang SC", "Microsoft YaHei", "Hiragino Sans GB", sans-serif`

- 基础单位 4px，常用间距 8/12/16/24/32px
- 卡片内边距 16px，卡片间距 16px
