## 1. Dashboard — 三种角色三套首页

### 1.1 财务会计 Dashboard

页面结构：顶部统计卡片行 + 下方近期活动列表。

**统计卡片（4 张）：**
- 📋 草稿凭证：显示数量，点击跳转 `/vouchers?status=draft`
- ✅ 待审核：显示数量，点击跳转 `/vouchers?status=audited`
- 📝 今日录入：今天录了多少张凭证 + 合计金额
- 📊 本月凭证总数

**快捷入口区：**
- 录入凭证 → `/vouchers/new`
- 科目余额表 → `/ledgers/trial-balance`
- AI 查询 → `/ai/query`

**近期活动列表：**
- 显示最近 5 条操作记录（谁、做了什么、什么时间）
- 格式："李四 审核了凭证 JZ-2026-06-045 · 2 分钟前"

**API:** `GET /api/v1/dashboard/summary?period_id=`

### 1.2 财务经理 Dashboard

**统计卡片：**
- 待审核凭证数（大号数字 + 红色角标如果 >0）
- 当前期间状态（开启/已结账）+ 距月末剩余天数
- 本月借贷合计（试算平衡快照）
- 异常提醒数（AI 检查未通过项）

**期末状态区：**
- 显示当前期间，结转执行情况（已完成/未完成）
- 快捷入口：期末结转 → `/period/carry`

**报表概览卡片：**
- 资产负债表关键指标迷你卡片：资产总计、负债总计、资产负债率
- "查看完整报表" → `/reports/balance-sheet`
- "🤖 AI 解读" 按钮

### 1.3 管理员 Dashboard

**系统概览卡片：**
- 👥 活跃用户数
- 📅 当前会计期间
- 💾 上次备份时间 + 备份大小
- 🗄️ 数据库状态（健康/异常）

**快捷入口：**
- 科目管理 → `/admin/accounts`
- 用户管理 → `/admin/users`
- 审计日志 → `/admin/logs`
- 数据备份 → `/admin/backups`

## 2. 凭证列表页 `/vouchers`

### 页面布局

顶部操作栏 + 筛选区 + 数据表格 + 底部分页。

**操作栏：**
- [+ 录入凭证] 按钮 → `/vouchers/new`
- [导入凭证] 按钮 → 打开导入对话框
- [批量打印] 按钮（选中后可用）
- 批量操作栏（选中行后出现）：批量审核 / 批量记账 / 批量导出 / 批量删除

**筛选区（DataTableToolbar）：**
- 日期范围选择器（从 → 到）
- 凭证号输入框
- 摘要模糊搜索
- 状态下拉：全部 / 草稿 / 已审核 / 已记账 / 已冲销
- 期间选择器
- 金额范围（从 → 到）
- [查询] [重置] 按钮

**数据表格列：**
| 选择框 | 日期 | 凭证号 | 摘要 | 借方金额 | 贷方金额 | 状态 | 操作 |
|--------|------|--------|------|----------|----------|------|------|

- 金额右对齐，等宽字体，千分位
- 状态用 StatusBadge 组件
- 行 hover 显示操作按钮组

**行操作按钮（按状态显示）：**
- 草稿：查看 / 编辑 / 删除 / 审核(需权限)
- 已审核：查看 / 反审核(需权限) / 记账(需权限)
- 已记账：查看 / 冲销(需权限) / 打印
- 已冲销：查看 / 打印 + 显示冲销来源链接

**底部合计行：** 固定底部，显示借方合计、贷方合计（筛选结果范围）。

**分页：** DataTablePagination — 页码 + 每页条数 + 总条数。

### 状态处理
- **加载：** 5 行骨架屏
- **空：** EmptyState "还没有凭证记录，点击录入凭证开始"
- **错误：** ErrorCard + 重试
- **网络断开：** 顶部红色 Banner

## 3. 凭证录入页 `/vouchers/new` — 核心页面

### 页面布局

```
┌─────────────────────────────────────────────────────┐
│  凭证录入                          [保存] [保存并新建]│
├─────────────────────────────────────────────────────┤
│  凭证号: 自动生成    日期: [日期选择器]              │
│  附单据: [数字输入] 张                                │
│                                                      │
│  ┌── 分录表格 ──────────────────────────────────┐  │
│  │  # │ 科目           │ 摘要    │ 借方   │ 贷方  │  │
│  │  1 │ [科目选择器 ▼] │ [____] │ [____] │ [____]│  │
│  │    │ (辅助核算显示) │        │        │       │  │
│  │  2 │ [科目选择器 ▼] │ [____] │ [____] │ [____]│  │
│  │    │               │        │        │       │  │
│  │ + │ [选择科目...]  │        │        │       │  │
│  └──────────────────────────────────────────────┘  │
│                                                      │
│  借方合计: 0.00    贷方合计: 0.00                    │
│  差额: 0.00  ✅ 借贷平衡 / ❌ 借贷不平               │
│                                                      │
│  [+ 新增分录] [从模板加载] [🤖 AI 生成]             │
└─────────────────────────────────────────────────────┘
```

### 分录表格交互细节

**每行分录字段：**
1. **行号** — 自动递增，不可编辑
2. **科目选择器** — 点击/输入展开树形下拉面板
   - 支持科目编码搜索（输入 "1001"）
   - 支持拼音搜索（输入 "chai" 匹配 "差旅费"）
   - 支持中文搜索（输入 "差旅"）
   - 树形结构，父科目分组显示，只能选末级科目
   - 键盘 ↑↓ 导航，Enter 选中，Esc 关闭
   - 选中后显示 "1001-现金" 格式
3. **辅助核算行** — 选中科目后，如果科目配置了 `aux_types`，在科目行下方展开辅助核算选择区
   - 每种辅助核算类型显示一个下拉选择器（如 👤 个人：[选择 ▼]）
   - 下拉支持搜索
   - 如果科目没配辅助核算，不显示此行
4. **摘要** — 文本输入框，必填，最大 200 字
5. **借方金额** — AmountInput，右对齐等宽，千分位
6. **贷方金额** — AmountInput，同上
   - 每行借方和贷方互斥：一个有值时另一个自动清空
   - 每行借方和贷方至少一个 > 0

**新增行：**
- 最后一行显示 "+" 占位符，点击或按 Enter 新增
- 新增行自动聚焦科目选择器
- 最少 2 行分录才能保存

**删除行：**
- 每行 hover 显示 × 删除按钮
- 至少保留 2 行

**行排序：**
- 拖拽行号区域可调整分录顺序

### 实时平衡指示器 (BalanceBar)

始终可见，实时计算：
- 借方合计：所有行借方之和
- 贷方合计：所有行贷方之和
- 差额：|借方合计 - 贷方合计|
- 差额 = 0 → 绿色 ✅ "借贷平衡"
- 差额 > 0 → 红色 ❌ "借贷不平，差额 X,XXX.XX"

### 快捷键

| 键 | 功能 |
|----|------|
| Ctrl+S | 保存 |
| Ctrl+Enter | 保存并新建 |
| Tab | 跳到下一字段（同行内：科目→摘要→借方→贷方→下一行） |
| Shift+Tab | 跳到上一字段 |
| ↑ | 移到上一行同列 |
| ↓ | 移到下一行同列 |
| Enter（最后一行） | 新增一行 |
| Esc | 关闭弹窗/下拉面板 |

### 表单验证

**失焦校验：**
- 科目：不能为空，红色边框
- 摘要：不能为空，红色边框
- 金额：每行借方+贷方至少一个 > 0
- 辅助核算：如果科目要求辅助核算，必须选择

**提交校验：**
- 至少 2 行分录
- 借贷合计必须相等
- 所有必填字段已填

**错误展示：**
- 字段下方红色文字
- 字段红色边框
- 平衡指示器红色
- Toast 提示具体错误

### 保存流程
1. 点击保存 → 前端校验 → 通过则 POST `/api/v1/vouchers`
2. 成功 → Toast 绿色 "凭证 JZ-2026-06-001 保存成功" → 跳转到凭证列表
3. 保存并新建 → 成功后清空表单，凭证号自动生成新号
4. 失败 → Toast 红色 + 错误信息（余额不平、期间已关账等）

### 从模板加载
- 点击按钮 → 弹窗显示模板列表（名称、描述、分录数）
- 选中模板 → 加载到分录表格
- 模板加载后用户仍可修改

### AI 生成入口
- 点击 "🤖 AI 生成" → 滑动面板从右侧滑入
- 面板内容：AI 凭证生成器（见 AI 章节）

## 4. 凭证详情页 `/vouchers/$id`

### 显示模式
右侧滑出面板（Sheet/Drawer），覆盖在当前页面上方，背景半透明遮罩。也可全页模式。

### 面板内容

**头部：**
- 凭证号 + 日期 + 状态标签
- 附单据数
- 制单人 + 审核人 + 记账时间
- 来源：手工/模板/AI/导入
- 关闭按钮 ×

**分录表格（只读）：**
- 行号 | 科目编码+名称 | 摘要 | 借方 | 贷方
- 辅助核算关联以标签显示（👤 张三、🏢 财务部）
- 金额等宽右对齐

**操作按钮（按状态和权限）：**
- 草稿：[编辑] [删除] [审核]
- 已审核：[反审核] [记账]
- 已记账：[冲销] [打印]
- 已冲销：[打印] + 链接到冲销凭证

**AI 对话记录（仅 AI 生成的凭证显示）：**
- 可折叠区域
- 显示原始描述
- 显示 AI 匹配的科目
- 显示用户做了哪些修改（diff 对比）
- "重新生成" 按钮

**操作日志：**
- 时间线格式
- 谁 + 什么操作 + 时间
- 如："李四 审核 · 2026-06-13 14:30"、"王五 记账 · 2026-06-13 14:35"

**冲销确认：**
- 点击冲销 → 弹窗选择：全额冲销 / 部分冲销
- 全额冲销：确认后 POST `/vouchers/{id}/reverse`
- 成功后显示冲销凭证号 + 链接

### 删除确认
- 弹窗 "确定删除凭证 JZ-001？此操作不可撤销。"
- 确认 → DELETE → 成功后关闭面板，列表刷新

## 5. 凭证模板 `/vouchers/templates`

### 模板列表页

- 表格：模板名称 | 描述 | 分录数 | 最后使用时间 | 操作
- 操作：使用（→ 跳转录入页并加载）/ 编辑 / 删除
- 新建模板按钮 → 模板编辑页

### 模板编辑页 `/vouchers/templates/new` 或 `/$id`

- 表单：模板名称（必填）、描述
- 分录表格（同凭证录入页，但无日期/凭证号/附单据）
- 分录可以保存为模板，不需要平衡
- 保存按钮 → POST/PUT `/api/v1/voucher-templates`
- 删除模板 → 确认弹窗

### 从凭证创建模板
- 凭证详情页 → "另存为模板" 按钮
- 弹窗输入模板名称
- 调用 POST `/api/v1/voucher-templates`

## 6. 凭证导入 `/vouchers/import`

### 导入流程（分步对话框）

**步骤 1：上传文件**
- 拖拽区域 + 选择文件按钮
- 支持格式：.xlsx, .xls
- [下载模板] 链接（下载标准 Excel 模板）

**步骤 2：列映射**
- 显示 Excel 前几行预览
- 下拉选择每列对应哪个字段（日期、科目编码、摘要、借方、贷方、辅助核算类型、辅助核算编码）
- 自动尝试匹配列名

**步骤 3：数据校验**
- 逐行校验：科目编码是否存在、金额是否有效、日期格式、辅助核算编码
- 有效行绿色 ✓，无效行红色 ✗ + 错误原因
- 统计：X 条有效，Y 条无效

**步骤 4：导入执行**
- 确认导入有效行
- 进度条
- 完成后显示结果：成功 X 条，失败 Y 条，生成的凭证号列表
- [查看凭证列表] → 跳转
